TOKENS & PRICING

Tokens & the Price You Can’t See

“A token is not a token. Five types, five prices, and the most expensive ones are invisible.”

Counting tokens tells you nothing about cost. What the meter actually charges depends on which of several priced classes a token falls into, which surface it's billed through, and a set of deployment choices made before a single token is spent.

Three surfaces, three billing units

Enterprise AI spend today runs through three metered surfaces a large organization typically uses at once: GitHub Copilot (billed in AI Credits, 1 credit = $0.01), Microsoft Foundry’s Azure OpenAI models (billed in USD per million tokens), and Microsoft Foundry’s Claude models (billed in Claude Consumption Units, 100 CCU = $1.00). All three ultimately resolve to the same underlying commodity (a priced token), but the credit and CCU wrappers exist for marketplace invoicing, not economics, and nothing reconciles them automatically. A cost model that treats these as one number is already wrong before it accounts for a single token class.

Five classes, five prices

Every model call bills across up to five distinct token types (input, reasoning, output, cache-write, cache-read), each priced independently, and priced differently again by model tier. Two patterns hold across the catalogue: cached input prices consistently around 0.1× base input on every vendor except Grok (0.25×), and cache write prices around 1.25× base input, but only on the newest model families — older models carry no cache-write charge at all. Long-context tiering (roughly doubling the input rate above a 200K–272K token threshold) applies to GPT, Gemini and Grok models, but not to Anthropic’s.

THE HIDDEN LINE ITEM

Reasoning tokens (chain-of-thought / extended-thinking content) are billed at the full output rate but never shown in the visible response. This is the single biggest cost most teams don’t know they’re paying, and it doesn’t stay put: on current-generation Claude models, a reasoning token bills as output when generated, then as ordinary input on every later turn it survives in context, then at the cache-read rate if it's ever read back from cache. A single semantic token can carry up to four different prices, set by model choice and harness design rather than by anything the user did.

The real cost formula

Cost is a sum across all five token classes and every model tier used in a pipeline, not token count × one price. A single call already carries five moving cost parts; an agentic task can make 10–200+ calls, each one repeating that same structure. This is the first thing a real cost model has to formalize, and it's why a vendor's single "total spend" line hides exactly the structure you'd need to optimize it.

GO DEEPER — Foundry runs two different cache-pricing regimes at once

Claude on Microsoft Foundry prices cache writes by retention duration: 1.25× base input for a 5-minute write, 2× for a 1-hour write. Azure OpenAI charges the same cache-write price regardless of retention, with retention set as a separate deployment parameter. A FinOps model that assumes one cache economics across a mixed Foundry estate will misprice half of it. Retention pricing exists because a longer hold is rent on scarce accelerator memory, not extra compute — the underlying operation is identical either way.

Underneath all of this, the multipliers track physically different resources rather than being arbitrary: prefill (processing a prompt) runs the accelerator near peak because every token is available at once; decode (generating one token at a time) is memory-bandwidth bound by roughly two orders of magnitude, because producing each token means streaming the whole model's weights out of memory again. That asymmetry is why output prices sit around 5× input rather than something far worse (continuous batching lets many sequences share one pass over the weights), and why a cache read, which skips prefill entirely, is priced so far below a fresh input token.

RATES MOVE FASTER THAN THIS PAGE

Every figure above was checked against Microsoft, GitHub and Anthropic documentation as of 27 August 2026. Pricing increases for EU Data Zone and non-US regional deployments take effect 1 September 2026. Treat every rate, multiplier and threshold here as directional, not a quoted price — verify current figures in the Azure pricing calculator before relying on them.

These three surfaces (Copilot, Azure OpenAI, and Claude on Foundry) aren’t only where spend happens; they’re also where it's seen. Each one's billing and usage telemetry is what makes per-task-class cost accounting possible in the first place, which is the same telemetry surface that downstream accountability and governance controls run on — covered on the Agentic Loop page and closed out on the final page.
