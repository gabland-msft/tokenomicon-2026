The Macro Hook

“You’re paying for AI work and you can’t tell whether it was worth it — and that’s not a tooling gap, it’s a structural problem.”

Before any framework or formula, there’s a two-minute story that names the actual failure, and a four-stop roadmap this hub spends the rest of its time filling in.

A number nobody could defend

A team spent $47,000 on tokens in a single month. Asked whether that spend was worth it, nobody on the team could answer: not because the number was hidden, but because nothing about it, on its own, tells you whether the work it bought was any good. (The figure is anonymized and illustrative, flagged as such here rather than presented as a real engagement number.)

Spend is not value

The team wasn’t flying blind on cost. They had good dashboards: line items by model, by day, by project, exactly what a mature FinOps practice is supposed to produce. What those dashboards couldn’t show was what any of that spend actually got them: output accepted per token, per task, per dollar. Cost visibility and value visibility are two different instruments, and this hub exists because most organizations built only the first one.

THE DISTINCTION THIS PAGE IS BUILT TO PROVE OUT

Spend ≠ value. A dashboard that only totals what left the wallet will always look complete and will never answer the one question that matters: did the money buy anything? Closing that gap is a unit economics problem — deciding what one token, one call, one agent run is actually worth — not a monitoring problem, which is only ever about counting what was spent.

Four circles, one left blank

That distinction sets the shape of everything that follows. This hub organizes around a four-theme map: Tokens → Loop → Yield → ? — what a token actually costs, what an agentic loop does to that cost, what yield means once cost and outcome are both on the table, and a fourth theme left deliberately open (Yield itself spans two segments below: the reframe and the instruments). It’s this hub’s genuinely open question, not an oversight — each of the six segments stands on its own, so read them in whatever order is useful; none of them, alone or in sequence, claims to close it.

GO DEEPER — cost visibility already has an industry; yield visibility doesn’t

FinOps practices have spent years building the tooling to answer "what did we spend" with real precision — by model, by team, by day, reconciled across invoicing systems. That machinery is mature and it works. None of it was built to answer "what did we get," because that question needs a second axis entirely: an accepted-outcome measure sitting next to the cost measure, not another way of slicing the same spend number. A team can have a perfect cost dashboard and still be exactly where the $47,000 team was — able to say precisely what left the wallet, with nothing to say about whether it was worth it. The rest of this hub is that second axis.
